# D Tech Academy - Product Overview

Institutional website for D Tech Academy, a technology education school based in Natal/RN, Brazil.

## Purpose
Presents the school's course catalog, enables student enrollment, and provides a virtual secretary for contact and support.

## Target Audience
Students and prospective students in the Natal/RN region interested in technology courses.

## Core Pages
- **Home** (`index.html`) — Intro video, course overview tables, quick contact form
- **Courses** (`pages/cursos.html`) — Full course catalog with details
- **Location** (`pages/localizacao.html`) — Map and address info
- **Virtual Secretary** (`pages/secretaria-virtual.html`) — Contact form + enrollment form

## Courses Offered
Desenvolvimento Web Full Stack, Python para Iniciantes, Banco de Dados SQL e NoSQL, Java Completo, Segurança da Informação, DevOps e Cloud Computing.

## Language
All content is in Brazilian Portuguese (pt-BR).
