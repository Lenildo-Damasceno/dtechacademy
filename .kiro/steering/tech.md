# Tech Stack

## Core Technologies
- HTML5 — semantic markup, `lang="pt-BR"` on all pages
- CSS3 — custom properties, flexbox, grid, responsive via media queries
- Vanilla JavaScript — no frameworks or build tools

## No Build System
This is a static site with no bundler, package manager, or compilation step. Open `index.html` directly in a browser to run it.

## Fonts
Google Fonts (Roboto) loaded via `<link>` tags in pages that need it. No local font files are currently in use.

## Common Commands
```bash
# Run locally — just open in browser
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

No npm, no build, no server required.
